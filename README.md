# Vietnamese Voice Cloning TTS

Clone any voice with just 10-30 seconds of audio.

## Features

- **Voice Clone**: Upload 10-30s reference audio + enter text = cloned speech
- **Record & Build**: Record multiple sentences for higher quality voice
- **ZeroGPU**: Free GPU-accelerated inference on HuggingFace Spaces

## Local Development

```bash
pip install -r requirements.txt
python app.py
```
